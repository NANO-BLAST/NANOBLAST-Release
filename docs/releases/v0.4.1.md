# NANOBLAST v0.4.1 — stable

3 November 2026. Tang Nano 20K + BL616.

This promotes the working CRT r12 build to the latest stable release at the
maintainer's request. Firmware and all four FPGA core payloads are byte-for-byte
identical to r12. If r12 is already installed and active, no reflash is needed.

## Changes since v0.4.0

- NES reset stays asserted until ROM loading and the menu/artwork SDRAM handoff
  complete. Divider/PPU state realigns at a defined reference-clock phase.
- The NES loader reports ready/error/reset/running state, and the MCU checks
  loader completion and reset release instead of silently assuming success.
- PAL/NTSC region changes apply at the next ROM load.
- CRT presets: Off, Light Scanlines, Strong Scanlines and CRT for NES/SMS.
- SNES-style A/B/Select/Start helpers and Select + Start menu access.
- “Loading game...” is centred within the menu, with progress below and no
  separate black loading box. The post-artwork 500 ms startup delay is removed.
- NES audio remains muted during menus, artwork updates, resets and loading.

SNES remains experimental. System 16 source/integration remains experimental
and is not included as a fifth built-in FPGA image.

## Installation

1. Leave NANOBLAST-v0.4.1-firmware.zip zipped and select it in NANOBLAST Flasher
   > Firmware & cores. Use the normal update process and retain the backup.
2. Select SMS/Game Gear, then NES/Famicom to activate the new NES core bank
   image. The firmware update preserves the saved FPGA power-on image.
3. Select the desired region and load a game. After hardware validation,
   optionally use Settings > Core boot flash to save NES for future power-on.

The unchanged Flasher v0.2.0 Apple Silicon installer is supplied for convenience.
It remains ad-hoc signed and not Apple-notarized. No new installer is required
for an existing Flasher installation that can select the firmware ZIP.

## Validation scope

The maintainer reports that r12 appears to be working and requested this stable
promotion. That report is recorded as hardware confirmation of the working
build; it is not an exhaustive compatibility, region or AccuracyCoin score claim.

The r12 NES image passed synthesis, routing, clock targets, all 61 storage pins
and all eight HDMI pad fuse checks. Loader/menu/phase regression tests, raw/ZIP
loading, audio mute, compressed decoding and persistence checks passed.
The full AccuracyCoin run was stopped at the maintainer's request and left for
manual validation. No new ROM test or board flash is performed for promotion.

The stable ZIP passes the actual Flasher parser/update planner. Its firmware
and four core payloads are checked against the original r12 package. The saved
power-on image, protected flash regions and existing backups remain preserved.
Prior r12 evidence is retained in the ZIP; its candidate wording is historical.
Current stable status and validation scope are defined by this README, the
manifest and stable-promotion.json.

No commercial ROMs, saves, credentials, device backups or toolchains are included.
Existing component licences apply. Matching browsable source and a source ZIP
are published alongside this release.
